# 首页布局精简设计

## 目标

精简首页顶部信息，并提高工具入口在桌面端的展示密度。

## 页面行为

- 首页不显示品牌副标题。
- 首页不显示顶部工具导航栏。
- 首页不显示“本地处理”和格式数量徽章。
- 进入任一具体工具页后，副标题、顶部工具导航栏和右侧徽章保持现状，确保用户仍可快速切换工具并查看处理信息。

## 工具入口布局

- 桌面宽度下每行展示 3 个入口。
- 中等宽度下每行展示 2 个入口，避免卡片内容过度拥挤。
- 手机宽度下每行展示 1 个入口。
- 工具顺序、文案、点击行为和视觉状态保持不变。

## 实现范围

- 在 React 页面组件中根据当前页面控制副标题、导航栏和右侧徽章是否渲染。
- 调整首页工具网格的 CSS 断点，不修改后端接口或其他工具页面。

## 验证

- 构建前端，确认 TypeScript 与 Vite 构建成功。
- 在首页确认副标题、导航栏和右侧徽章不可见，工具页确认三者仍可见。
- 检查桌面、平板和手机宽度下分别为 3、2、1 列。
