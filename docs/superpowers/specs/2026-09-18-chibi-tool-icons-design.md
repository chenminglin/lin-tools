# Q 版角色功能入口图标设计

## 目标

使用现有的 Q 版主持人角色，为首页 11 个功能入口制作具有一致视觉语言、可在小尺寸下清晰识别的专属图标。图标只用于首页入口卡片，顶部导航继续使用现有 Lucide 线性图标。

## 角色与视觉规范

- 以 `/Users/bethenachan/code/make_video/actor/chibi-host-pose-sheet.png` 为角色参考图。
- 保留角色的黄色贝雷帽、黑色短发、白色上衣、蓝色围裙、圆润面部和深蓝粗描边。
- 每张图采用半身构图，角色大小、视角、描边粗细和视觉重量保持一致。
- 使用透明背景，不添加文字、品牌标志、水印、边框或固定底色徽章。
- 每个图标仅使用一至两个主要道具，通过动作、表情和道具区分功能。
- 原始资产为 1024×1024 PNG，页面按约 56–72px 显示；构图需保证缩小后仍能辨认。

## 图标内容映射

| 功能入口 | 图标内容 |
| --- | --- |
| 视频裁剪 | 角色拿着大剪刀，剪开一段胶片 |
| 视频合并 | 角色把两段胶片拼接到一起 |
| 同步播放 | 角色双手各举一个播放窗口，两个窗口都有播放符号 |
| 提取音频 | 角色从视频画面中拉出一条音符轨道 |
| 音频编辑 | 角色戴耳机，操作带滑块的音频波形 |
| 音频变速 | 角色拿着音符，旁边配速度表与动感线 |
| 图片去水印 | 角色用魔法橡皮擦清除图片上的淡色印记 |
| 图片改尺寸 | 角色双手拉伸图片边框，四角带缩放箭头 |
| 比例计算器 | 角色拿计算器和带比例标记的画框 |
| 视频下载 | 角色接住从云朵落下的视频文件 |
| 模型下载 | 角色抱着带神经网络节点符号的下载箱 |

每个功能使用独立 PNG，不使用精灵图，以便后续单独替换或重新生成。

## 前端接入

- 首页工具配置增加图标图片路径，同时保留原有 Lucide 图标组件作为加载失败时的后备。
- 首页入口卡片优先渲染角色 PNG；图片加载失败时显示对应 Lucide 图标，避免入口留白。
- 为角色图标设置统一的显示框、对象适配规则和轻微悬浮反馈。
- 不修改入口顺序、标题、描述、分类、路由、卡片布局或顶部导航图标。
- 不修改后端接口与功能处理逻辑。

## 生成与验收

每张图片以角色参考图为身份和风格依据，分别生成，避免用一张大图裁切导致动作细节和透明边缘不稳定。逐张检查：

- 角色关键外观与参考图一致。
- 道具和动作准确表达对应功能。
- 背景具有真实透明通道，没有棋盘格烘焙背景。
- 没有文字、乱码、品牌标志或水印。
- 人物未被画布边缘截断，四周留白一致。
- 缩小至首页实际显示尺寸后仍可快速区分。

接入后运行现有前端测试与生产构建，并检查桌面、平板和手机宽度下的首页入口显示。图片加载失败场景需验证 Lucide 后备图标正常出现。
