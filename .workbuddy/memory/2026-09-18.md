## 全站样式统一美化（frontend/src/styles.css）

用户要求「美化页面样式」，确认范围后选择**全部页面统一美化**。

**改动文件**：仅 `frontend/src/styles.css`（2612 → 2768 行）。**纯样式层重构，未动任何 TSX/组件结构**，
所有类名一一保留，因此功能零风险。`frontend/dist` 已重新构建（产物被 gitignore）。

**原样式的实际问题**（诊断结论）：
- 没有设计令牌层，40+ 处硬编码 hex（`#f8faff`/`#c7d2fe`/`#edf2f7`/`#f5f7ff` 等）散落各处
- 圆角用了 9 个不同数值（6/9/10/12/14/16/18/20/24px）
- **字重失控**：全站几乎都是 `font-weight: 800/900`，标题和正文一样粗，层级全无
- 焦点态、过渡时长、阴影各写各的（`0 14px 35px`/`0 16px 35px`/`0 10px 22px`）
- 有 6 个类在 TSX 里被使用但 CSS 从未定义（`info-panel`、`audio-info-panel`、`audio-progress`、
  `audio-silence-panel`、`audio-trim-panel`、`is-landscape`）

**做法**：建立完整令牌层（品牌色阶 / 中性色 / 语义色 / 圆角 6 档 / 阴影 5 档 / 字体栈 / 动效曲线 /
焦点环 / 布局宽度），再把所有组件改为引用令牌；字重收敛到真实层级（600 为主）；
统一 `:focus-visible` 焦点环与 140/180/260ms 三档过渡。硬编码 hex 从 111 降到 54（其余在令牌块内）。
顺带补齐上述 6 个未定义类。

**设计方向依据**：用 ui-ux-pro-max 查得本产品属「Developer Tool / Productivity Tool」，
推荐风格为 Minimalism & Swiss Style + Flat Design + 微交互，故**保留原有 slate + indigo 识别度做精修**，
而不是推翻重做。注意 `--design-system` 的默认输出偏向营销落地页（Feature-Rich Showcase / Vibrant），
对工具类应用不适用，需人工判断否决。

**验证**：`npm run build` 通过；12 个页面全部 1440px 截图看过，无塌陷；
390px 真机视口（CDP `Emulation.setDeviceMetricsOverride`）下无横向溢出。

**环境坑（已写进 local-webapp-nextjs-python 技能）**：

以后做注入式预演必须当场说明「图片是注入出来的，代码还没改」。

**本轮改动（3 个文件）**：
- **新增 `frontend/src/theme.css`**（皮肤层，约 340 行）：`@font-face` + 令牌覆盖 + 组件覆盖
- **新增 `frontend/src/fonts/fredoka.woff2` + `nunito.woff2`**（共 72KB）
- **`main.tsx`**：`import './styles.css';` 后加一行 `import './theme.css';`
- 回退方式：删 theme.css + 删那一行 import（styles.css 未改动本轮）

**渲染用令牌**（沿用参考图实测值）：`--bg #fff9f6` / `--border #2d3748` / `--brand-600 #22c55f` /
硬投影 `2/3/4/6px 偏移 0 模糊` / 圆角 `10/12/14/18/22 + pill` / Fredoka 标题 + Nunito 正文。

**关键决策与实测坑**：
- **字体做成本地自托管**，不用 Google Fonts —— 本地工具要能离线跑。
  实测 Google Fonts CSS2 里 Fredoka 各字重、Nunito 各字重指向的都是**同一个可变字体文件**
  （md5 全同），所以每个 family 只留 1 份，用 `font-weight: 300 700` 范围声明即可。
  原令牌里的 `"Space Grotesk"` / `Inter` 全项目搜不到 @font-face，**从来没加载过**，一直是系统回退字体。
- **绿底配墨字**（5.2:1）而不是白字（2.3:1），过 AA。
- **会换行的容器不能套胶囊圆角**：`.filter-list`（创意滤镜 6 项 3 行）套 pill 后
  被撑成一个巨大椭圆，实测截图才发现。已改为 `--r-lg` 容器 + `--r-md` 子项。
  单行的 `.segmented-control` / `.ratio-presets` / `.speed-presets` 继续用 pill。
- **嵌套卡片降级用一条 `:is()` 规则**，没有枚举 `.A .B` 组合：
  `:is(卡类…) :is(卡类…) { box-shadow:none; border-width:2px }`，特异性 (0,2,0) 天然压过单类规则。
  这一步解决了我上一轮预警的「工具页宫格打架」问题。
- **禁用按钮不要整体 `opacity: .55`**：绿底半透明后墨字几乎糊掉。改成灰底 `#f7f1ea` + 保留墨边 +
  `--text-2` 文字 + 去阴影。
- **换主色前必须搜不随令牌变的硬编码色**：`rgba(79, 70, 229, …)` 有 3 处
  （`.video-toolbar strong`、`.trim-selection` 底色、`.trim-handle` 光晕），
  只覆盖令牌会得到「绿描边 + 紫底」撞色，已单独覆盖。

**真 before/after 的做法**：临时把 `import './theme.css'` 注释掉 → build 截 before →
恢复 → build 截 after。两次 CSS 产物哈希不同可佐证（before `index-Bbtk-noR.css` 39.51KB /
after 49.35KB）。对比图：`/tmp/lin-shots/compare-1.png`（首页+裁剪页）、`compare-2.png`（合并+音频）。

**验证**：`tsc --noEmit` + vite 构建通过；12 个页面 1440px 截图逐一查看；
390px 真机视口（CDP 模拟）无横向溢出，导航 dock 横向滚动正常。
